npm reads package-lock.json (v2/v3), npm-shrinkwrap.json or package.json in the selected directory. Python requirements.txt produces a partial inventory; use Python installed environment after creating a virtual environment inside the workspace to include installed dependencies. Java requires built JAR/WAR/EAR files and dependencies. Syft reads existing files; it never builds your application.
